# Sweet Crumb Bakery — Assignment 6

## Project Overview

Sweet Crumb Bakery is a responsive bakery ordering website developed as part of our Front-End Development course.

The website allows users to explore bakery products, browse the gallery, view product information, and interact with order and contact forms.

For Assignment 6, we extended our previous project by implementing interactive features using **jQuery**, while maintaining the existing HTML, CSS, Bootstrap, and JavaScript functionality.

## Technologies Used

- HTML5 — website structure
- CSS3 — styling and responsive design
- Bootstrap 5 — layout and components
- JavaScript — DOM manipulation, validation, and interactive features
- jQuery — live search, animations, event handling, and dynamic content
- GitHub — version control
- GitHub Pages — website deployment

## Website Pages

1. **Home** — bakery introduction, image carousel, interactive features, and animated statistics.
2. **Menu** — product cards, category filters, real-time search, autocomplete, and search highlighting.
3. **About** — bakery information, values, production process, and searchable FAQs.
4. **Gallery** — bakery images, carousel, and lazy image loading.
5. **Order** — order form with input validation, loading spinner, and notifications.
6. **Contact** — contact information, contact form, email copying, and notifications.

## Assignment 6 — jQuery Features

| Task | Feature | Description |
|---|---|---|
| Task 0 | jQuery Setup | jQuery CDN and `$(document).ready()` |
| Task 1 | Real-time Search | Filters bakery products as the user types |
| Task 2 | Autocomplete | Displays matching product suggestions |
| Task 3 | Search Highlighting | Highlights matching keywords in products and FAQs |
| Task 4 | Scroll Progress Bar | Displays colorful page scroll progress |
| Task 5 | Animated Number Counter | Animates statistics on the Home page |
| Task 6 | Loading Spinner | Displays a spinner and temporarily disables submit buttons |
| Task 7 | Toast Notifications | Shows temporary messages after user actions |
| Task 8 | Copy to Clipboard | Copies the bakery email and displays confirmation |
| Task 9 | Image Lazy Loading | Loads gallery images when they approach the viewport |

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Navigate through the six website pages.
5. Test the interactive features.

An internet connection is required to load the jQuery and Bootstrap libraries from their CDNs.
